Нужен ли React для стекла?

Нет. Стекло — это CSS. В этом демо используется нативный HTML, CSS и Web Animations API. React и Motion полезны для более сложных состояний приложения.

Что происходит без backdrop-filter?

Включается плотная поверхность. Контент, фокус и границы остаются видимыми. Тот же режим можно включить вручную в лаборатории.

Как отключается движение?

Системная настройка уменьшения движения и переключатель в лаборатории останавливают активную анимацию. Интерфейс сразу показывает конечное читаемое состояние.

Это настоящий продукт?
