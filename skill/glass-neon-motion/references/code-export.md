# Переносимые образцы и тема

Экспорт добавляется поверх проверенного атласа, а не заменяет статусы покрытия. Рабочий локальный компонент, визуальная композиция, HTML-рецепт и media-control без медиа сохраняют разные обещания. В проекте LUMA экспортируются 366 авторских образцов; сторонние изображения-референсы не входят в экспорт.

## Контракт примера

- HTML, CSS и JavaScript — три согласованных файла. Указывай имена подключений. Автономный HTML объединяет их и необходимые локальные ресурсы.
- Экспортируй исходное состояние выбранного образца и минимальные оболочки его разметки. Не добавляй соседние скрытые карточки ради обработчиков. Не включай пользовательский ввод, выбранные файлы, cookies, хранилища или историю.
- Общие исходники CSS/JS могут храниться одним ресурсным пакетом; экземпляры собираются по запросу. Не дублируй полный пакет сотни раз. Сверяй пакет с актуальными исходниками при сборке.
- Сохраняй ссылки на источники и лицензии реально включённых шрифтов/иконок. Не назначай сторонним или авторским исходникам выдуманную лицензию.
- Clipboard: успех только после разрешения Promise. Отказ/отсутствие API — выделяемый текст для ручного копирования. Смена вкладки, образца или настроек во время ожидания не должна выдавать устаревший payload за текущий.
- Нативный dialog: видимый заголовок, клавиатура, Escape, возврат фокуса. Код прокручивается внутри textarea, не расширяет экран.

## Тема

Светлая и тёмная палитры, поверхность Clear/Frost, край Film/Depth и размеры — независимые параметры. Радиус панелей и плотность отступов не заменяют минимальные размеры интерактивных целей. Материал сравнивается на прежнем фоне; демонстрационные карточки фиксированных материалов сохраняют собственные настройки.

Экспортируй CSS-токены, сериализуемые настройки и runtime только при наличии JS-анимаций. Проверяй числа/цвета/длительности до применения. Расчёт контраста на выбранной подложке не заменяет проверку композиции с реальным фоном. Изменение темы отменяет текущий декоративный переход, новые переходы используют выбранные timing/easing. Системное reduced motion имеет приоритет и работает при живом переключении.

## Приёмка

Проверяй скачанный файл по file:// с заблокированной сетью: ресурсы, отсутствие ошибок и реальное действие. Массовая загрузка всех образцов проверяет только загрузку, ресурсную автономность и layout; функциональные сценарии проверяются отдельно. Проверяй обе темы, узкую ширину, фокус, отмену движения, forced colors и no-transparency fallback. Чётко разделяй исходники, браузерную проверку, push и публичный read-back.
