# Направление по референсам Ивана — 2026-10-21

Это project-specific подборка LUMA, а не универсальная стилистическая норма. Из 24 пронумерованных ссылок 23 уникальны: №19 повторяет №5; №25 пуст. Все наблюдения относятся к статичным изображениям; скорость, easing и взаимодействия источников не проверены. Полный список источников хранится в опубликованном атласе проекта.
