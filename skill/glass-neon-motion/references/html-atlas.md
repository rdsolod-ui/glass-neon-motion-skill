# Семантика → элемент → состояние

Карта HTML — проверяемый инвентарь, а не обещание работающего продукта. При запросе «все элементы» сверяй набор с актуальным [WHATWG index](https://html.spec.whatwg.org/multipage/indices.html#elements-3). Фиксируй дату и область: conforming tags, отдельно obsolete, экспериментальные элементы и чужие пространства имён SVG/MathML. Custom elements имеют неограниченное множество имён и описываются как механизм. Нельзя объявлять покрытие полным по произвольному списку популярных тегов.

## Четыре слоя карты

1. **Нативные теги:** метаданные и корень документа, секции/landmarks, заголовки, текстовая семантика, списки, таблицы, медиа, формы, disclosure/dialog, scripting/templates. У служебного элемента нет искусственно придуманной кнопки-превью: покажи его роль и безопасный код.
2. **Типы ввода:** все стандартные значения `input type`, плюс `select`, `textarea`, `datalist`, `button`, `output`, `meter`, `progress`. Сверяй [MDN input](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/input); внешний вид date/color/file зависит от браузера и ОС.
3. **Составные паттерны:** segmented selector, tabs, combobox, listbox, menu, multi-select/chips, disclosure, dialog, pagination, toast, toolbar. Это композиции элементов и поведения, не новые HTML-теги. Для сложной клавиатуры предпочитай проверенные primitives, если они уже есть в проекте.
4. **Состояния:** rest, hover, focus-visible, active, selected/checked, disabled, readonly, required, invalid/error, busy/loading, success, empty. Состояния показывают семантику и статичный сигнал; анимация необязательна.

## Правила образцов

- Нативная кнопка вызывает действие; ссылка ведёт к реальному адресу. Не превращай `div` в кнопку ради стеклянной поверхности.
- У каждого поля есть постоянный label; группы используют legend; ошибка связана через `aria-describedby`. Placeholder не заменяет label. `aria-invalid` не равно нативной validation.
- Disabled, readonly и busy не взаимозаменяемы. Toggle сообщает `aria-pressed`, checkbox — checked, tabs — selected и связь с panel.
- Реальная форма демо блокирует внешнюю отправку, но сохраняет проверку ограничений и честный локальный результат. File input не означает загрузку на сервер. Пустой media player не означает воспроизведение.
- Код чужих примеров отображается как текст. Не исполняй произвольные scripts, base, iframe, object или внешние ресурсы ради каталога. Изолируй примеры от навигации и landmark-структуры страницы.
- Для glass skins оставляй читаемый фон поля, различимые границы интерактива и focus. Запрет равномерной декоративной стеклянной обводки не запрещает функциональные границы таблицы/поля.
- Сверяй число уникальных записей с фактическим inventory. Не суммируй типы ввода и состояния в число HTML-тегов.

## Приёмка

Проверить поиск тегом и русским именем, независимость фильтров, отсутствие дублирующихся id, все типы ввода, возврат focus из dialog, выбор стрелками/Space/Enter, длинное значение, 320 px и zoom, no-JS, две темы, solid/forced-colors. Каталог сверяется с источником отдельно от browser QA живых компонентов.
