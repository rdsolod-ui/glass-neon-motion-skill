# Подборки и типографика

Избранное и именованные подборки сохраняются локально в браузере, без аккаунта и облачной синхронизации. Сохраняй стабильные ID при расширении атласа. Повреждённое или недоступное хранилище не должно блокировать выбор и скачивание.

Общий автономный HTML фиксирует одну текущую тему. Каждый выбранный оригинальный образец получает изолированный документ iframe: локальные ID, radio groups, формы и диалоги не конфликтуют. CSS, шрифты, тема и runtime каждого семейства включаются один раз и подключаются через Blob URL. Это переносимая демонстрационная подборка, не готовый единый production DOM. Серверные интеграции отсутствуют. Не экспортируй введённые пользователем данные. Сохраняй лицензии и честный статус примеров.

Для текущего LUMA brief: только прямые гротески, никаких засечек и курсива. Manrope 200–800 уже поставляется с кириллицей и OFL; акценты используют 700–800, основной текст 400–600. Семантические em/cite сохраняются с прямым начертанием. Код использует системный моноширинный шрифт. Не синтезируй отсутствующие начертания.

Карта 24 ролей: display, hero, заголовки, лид, основной и длинный текст, цитата, надзаголовок, подпись, label/help, feedback, action/navigation, KPI, цена, таблица, списки/определения, код/клавиши, условия, emphasis, empty, кириллица/латиница и три киноэтюда.

Motion-score: WAAPI владеет transform/opacity/clipPath на дочерних текстовых блоках. Одно появление при попадании в viewport, ручной replay; 900 мс и stagger до 450 мс. Повтор отменяет предыдущее движение. Статический текст виден без JS. Системный и пользовательский reduced motion отменяют активные анимации, pagehide очищает observer/listeners. Проверяй длинный текст, 390 px, keyboard, live reduced, offline mixed export и сохранение после reload.


## Перенос и порядок

JSON `luma-collection`, version 1 содержит name, упорядоченные stable ids и theme. Импорт создаёт новую подборку, не перезаписывает существующие, применяет проверенную тему. Максимум файла 1 МБ, 1000 входных ID, 80 символов имени; дубликаты ID удаляются, неизвестные пропускаются с сообщением. Полностью неизвестная или повреждённая подборка отклоняется до изменения состояния. Не выполняй код из JSON, выводи имена через textContent.

Drag/drop и нативные кнопки Выше/Ниже меняют одну последовательность выбранных ID. Кнопки доступны клавиатурой, после перестановки фокус остаётся на строке. JSON и HTML экспорт используют тот же порядок. Сохранение/обновление подборки фиксирует текущую тему; открытие восстанавливает её, старые записи без темы сохраняют текущую. Дублирование создаёт независимую копию. Проверяй реальный download/import в чистом контексте, malformed JSON, неизвестные ID, live тему, порядок после reload и работу keyboard.


## Предпросмотр и ZIP

Предпросмотр использует тот же сборщик, что общий экспорт, и сохраняет порядок. Три ширины 1200/768/390 px доступны в scrollable viewport; на узком устройстве широкая виртуальная область намеренно прокручивается. Native dialog закрывается Escape с возвратом фокуса. Изменения темы/материала/плотности/размера текста/веса сохраняются в общей теме. Масштаб текста .85–1.2, вес 600/700/800; повторно проверь переносы.

ZIP STORE без зависимости содержит index.html, collection.css, collection.js, theme.json, LICENSES.txt и README.txt. Это изолированные рабочие демонстрации, не объединённый production DOM. Проверяй CRC, распаковку, file:// offline и реальные действия, а не только наличие download.

Цветовые варианты: violet/cyan/rose/amber, разные значения для light/dark и CanvasText в forced colors. Дополнительные WAAPI эффекты focus/slide/depth/curtain/tracking/cascade конечные, отменяются при replay, live reduced и pagehide. Текст остаётся виден без JS. В атласе 35 типографических образцов, общий объём 401.

Галереи website-reference-pack: Supahero (сообщает о переходе к Screensdesign), Pricing Pages, Navbar Gallery, CTA.gallery, Footer Design. Проверены 2026-10-23. Это пять источников референсов; website-components — отдельный маршрут к готовому коду. Не называй их шестью галереями без подтверждения и не копируй их assets без лицензии.
