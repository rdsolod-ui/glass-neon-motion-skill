Файл `.codex/agents/glass_design.toml` прочитан вручную после запуска; это применение инструкций, не доказательство native discovery. Ownership: только этот brief.

## Замысел и состав

Иван проверяет различие плоской стеклянной плёнки и визуальной толщины. Один крупный оригинальный CSS specimen, одинаковая подложка и геометрия в обоих режимах. Контролы меняют только материал и условия просмотра. Основной сайт, его CSS и сборка не меняются.

Заголовок: «Один материал. Два характера края». Текст: «Сравните плёнку без толщины и оптический край с направленным бликом». Краткая подпись: «CSS-аппроксимация, без физической рефракции». Все важные объяснения — на плотном фоне вне стекла; на specimen допустим только короткий маркер «LUMA / 01».

Desktop: ограниченный контейнер 1120 px, поля 32 px; текст/контролы и сцена в колонках 0.8fr / 1.2fr. При ширине до 700 px — один столбец, поля 18 px. Стекло занимает около 65% сцены и перекрывает отчётливо видимый cyan/lime объект: часть объекта остаётся снаружи резкой, часть под панелью размывается. Не обрезать документ, маскируя overflow; декоративная сцена может иметь собственное ограничение.

## Материальный контракт

| Режим | Реализация | Кадр приёмки |
| --- | --- | --- |
| 2D-плёнка, default | Прозрачная заливка + backdrop blur 16–22 px. Нет border, outline, inset rim, bevel и тени, создающей толщину. Граница определяется диффузией/светопропусканием. | Видно резкий внешний и рассеянный внутренний сегмент одной подложки; нет непрерывной линии по краю. |
| 3D-кромка | Та же плоскость. Отдельные локальные блики сверху слева и короткий отражённый фрагмент снизу справа, затухающие до углов. Локальная внутренняя тень и мягкая опорная тень дают визуальную толщину. | Блик направлен и прерывист; большая часть периметра остаётся без светлой обводки. |

Функциональный `:focus-visible` и системные forced-colors контуры обязательны и не являются запрещённой эстетической обводкой. Solid fallback даёт плотную поверхность без backdrop filter; reduced-transparency и отсутствие backdrop-filter выбирают такой же читаемый режим. В forced colors декоративные объекты и блики исчезают, текст/контролы сохраняются.

## Поведение и движение

Нативный fieldset с radio «2D-плёнка» / «3D-кромка», кнопка темы с понятным состоянием, checkbox «Плотный фон». Смена режима обновляет видимый заголовок/описание без сдвига фокуса. Состояние должно читаться не только по цвету. Enter/Space/стрелки работают согласно нативной семантике.

| Назначение | Триггер | Владелец | Время / прерывание | Reduced / cleanup |
| --- | --- | --- | --- | --- |
| Сравнение материала | Radio change | DOM state + CSS | Мгновенно, последний выбор | Тот же конечный вид; нет фоновых таймеров |
| Условия просмотра | Theme/solid control | DOM state + CSS | Мгновенно | Тот же вид; CSS media реагирует live |
| Необязательная press обратная связь | Fine pointer press | CSS transform | 140 ms, release возвращает | Без transform/transition при reduce; hover только hover:hover/pointer:fine |

Нет автоматически вращающихся сфер, бесконечного shimmer, cursor tracking, анимации blur или очереди переходов. Статический материал демонстрирует различие надёжнее движения.
