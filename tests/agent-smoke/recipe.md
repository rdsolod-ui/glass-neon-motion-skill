# Переносимый рецепт материала

Авторство: `/root/runtime_contract`, дополнительное назначение координатора по прочитанным developer instructions `glass_skill`. Это fallback assignment; отдельный native launch `glass_skill` подтверждён только диагностическим smoke.

**Статус: recipe.** Реализация и её QA находятся в [index.html](index.html), [design.md](design.md), [qa.md](qa.md). Этот документ не устанавливает библиотеку и не меняет основной skill.

1. Построй общий цветной substrate, часть которого остаётся видимой снаружи образца. Для 2D используй прозрачную заливку и backdrop diffusion без базового border, inset bevel или объёмной тени.
2. Для 3D добавь локальные затухающие блики сверху/сбоку и направленную внутреннюю тень. Равномерный stroke по периметру не является толщиной. CSS имитирует рассеивание и визуальную кромку, а не физически точную рефракцию.
3. Отдели читаемый текст от наиболее пёстрого участка образца. Light и dark имеют самостоятельные цветовые токены; палитра LUMA не обязательна для других проектов.
4. Оставь semantic controls, keyboard focus-visible и системные границы forced-colors. Без backdrop-filter и при reduced transparency нужен непрозрачный читаемый fallback.
5. Короткий переход состояния допускается только для понятной обратной связи; reduced motion до load и при live change немедленно убирает переход. Бесконечные декоративные циклы не нужны.

Перенос: достаточно текущего HTML/CSS/JS стека, без обязательных React/GSAP/WebGL зависимостей. Перенос на другой фон, размер, шрифт или browser требует повторной проверки composited contrast, узкого экрана, focus/touch и различимости 2D/3D. Проверка одного Chromium не доказывает Safari, мобильное устройство или универсальную производительность.
