## Контракт самостоятельного кода

1. Выбранный HTML, CSS и JS в панели образуют заявленный пример. Если есть общий bootstrap, wrapper, theme API или стили, они включены либо явно перечислены; кнопка скачивания целого HTML включает их автоматически.
2. Самостоятельный файл открывается в новом документе без запущенного moodboard, `window.GlassLab`, `UIAtlas`, соседних карточек, служебных фильтров и скрытого HTML всего атласа. Проверка перехватывает сетевые запросы и блокирует внешние зависимости; fallback-шрифт допустим, если оригинальный файл шрифта не включён и это указано.
3. Для рабочего образца проверяется реальное действие и результат, а не только наличие кнопок. Для visual/recipe проверяется статический результат и честная подпись. Повторная вставка одного и того же ID в одну страницу не считается поддержанной без отдельного контракта инстансинга.
4. Самостоятельная JS-версия сохраняет cleanup, finite motion, live reduced, клавиатуру и диалог. Без JS остаётся содержимое и нативное поведение; JS-only команды не создают ложное впечатление работы.
5. HTML/CSS/JS доступны как текст для копирования; строка `</script>`, обратные кавычки, Unicode и CSS `url(...)` не ломают оболочку файла. Код в UI выводится как текст, не исполняется из preview-панели.
6. Не следует хранить 322 копии полного CSS/JS bundle в репозитории. Общие источники и сборка по требованию дают тот же автономный результат без ненужного многократного payload.

Источник выявленного архитектурного риска: `site/html-atlas.js` предполагает общий search/count/root; `site/motion-atlas.js` предполагает отдельные `scroll`, `knob`, `track` даже для других карточек. Эти whole-atlas entrypoints нельзя без адаптации вставить рядом с единственной карточкой. Модули UI принимают root/API и лучше подходят к scoped bootstrap, но API также должен попасть в экспорт.

## Копирование и скачивание

| Сценарий | Критерий |
|---|---|
| Clipboard fulfilled | В тестовом перехвате передан точный текущий текст; подтверждение появляется после resolved Promise |
| Clipboard rejected / API отсутствует | Никакого ложного «скопировано»; код остаётся выделяемым, есть инструкция ручного копирования и download |
| Быстрый повторный выбор HTML→CSS→JS | Поздний Promise не подписывает прежний payload как новый; состояние относится к тому же snippet/tab |
| Download | Браузерное событие загрузки, разумное имя/расширение, непустые реальные bytes; UTF-8 и кириллица читаются повторно |
| Object URL lifecycle | URL освобождается после начала скачивания; повторные экспорты не копят живые Blob URL |
| Диалог | Native modal либо полноценный эквивалент: focus внутри, Escape, возврат к исходной карточке, доступное имя |
| Длинный код | Внутренняя прокрутка, 390/320 px без расширения всей страницы; keyboard/touch достижимы copy/download/close |

Чтобы не читать и не затирать неизвестный пользовательский clipboard, основной тест захватывает только аргумент `writeText` текущего действия и моделирует success/reject. Это проверка интеграции API, а не доказательство системного вставления во все приложения. Реальные скачанные bytes проверяются отдельно.

## Экспорт готовой темы

- Стекло: выбранные матовость/прозрачность и край независимы; исходный LUMA default clear/depth сохраняется. Экспорт не подменяет параметры лаборатории другим материалом без подписи.
- Цвет: light/dark значения настроены явно; акцент, ink, surface и focus попадают в артефакт и реально применяются к новому примеру. Валидные CSS-значения, нет `undefined`/`NaN`/неразрешённых ссылок на отсутствующие vars.
- Motion: токены не только перечислены. Preview/экспортированный пример читает их; изменение длительности даёт наблюдаемую разницу. Live reduced отменяет движение и оставляет конечное семантическое состояние.
- Roundtrip означает: выбранные настройки → файл → повторное применение в новом документе → сверка computed styles и поведения. Новый интерфейс импорта JSON не обязателен, если пользователь его не просил.
- Solid/reduced transparency/forced colors и `:focus-visible` остаются в теме. Контуры системной доступности не удаляются под видом запрета декоративного outline.
- Сохраняются лицензии выбранных локальных иконок; внешние фотографии/референсы не включаются как собственные assets.

## План независимых проверок

Сначала статический manifest coverage всех коллекций, уникальные ID и экспортные статусы; затем несколько изолированных представителей каждого семейства с реальным действием (включая chart, icon, dialog, native form, canvas, drag/scroll и material). Для больших наборов дополнительно автоматический load/error/resource smoke всех экспортов с явно разделённым поведением: отсутствие ошибки не равно полноценной приёмке каждого сценария.

Отдельно: Clipboard success/reject/missing API; загрузка реального файла и его UTF-8; HTML/CSS/JS соответствие; full HTML offline; экспорт темы и roundtrip; no-JS; desktop обе темы, mobile390/320; keyboard/touch; reduced до load и live. Browser baton выполняется последовательно: в прошлой среде параллельная CDP media emulation давала противоречивый read-back.

Severity: HIGH/P1 — заявленный рабочий экспорт не работает, нет доступного восстановления после clipboard отказа, потеря/искажение скачанных данных, motion игнорирует reduced, необоснованное исполнение текста. MEDIUM/P2 — отдельная потеря состояния/контекста/семантики, недостоверная подпись coverage, заметное clipping. LOW/P3 — локальная полировка. Принять можно только проверенный scope без открытых HIGH/P1.

## Проверенные официальные API

`writeText` возвращает Promise и может отклоняться при запрете; доступ зависит от secure context. Поэтому требуется честный fallback. [MDN Clipboard.writeText](https://developer.mozilla.org/en-US/docs/Web/API/Clipboard/writeText).

Созданный Blob URL нужно освобождать. [MDN URL.createObjectURL](https://developer.mozilla.org/en-US/docs/Web/API/URL/createObjectURL_static). Строки Blob кодируются в UTF-8; MIME и окончания строк задаются отдельно. [MDN Blob](https://developer.mozilla.org/en-US/docs/Web/API/Blob/Blob).

Native `showModal` предоставляет модальное поведение; фактический focus и возврат проверяются в браузере. [MDN HTMLDialogElement.showModal](https://developer.mozilla.org/en-US/docs/Web/API/HTMLDialogElement/showModal).
