Сохранены HTML/CSS/JS стек, начальный Clear + Depth, источники и существующие URL. Подключены ранее незавершённые заготовки Theme Studio и изолированные HTML/motion bootstrap. Добавлены радиус и плотность, отдельные HTML/CSS/JS вкладки, скачивание единого HTML и сборка общего ресурсного пакета.

## Проверенный объём

- Инвентарь из авторских генераторов: 366 образцов. Массовая изолированная загрузка на 390 px: один specimen на файл, без внешних запросов, JS-ошибок и document overflow. Это smoke загрузки, не все возможные действия всех элементов.
- Отдельные действия: календарь, товар без соседней корзины, dataset графика, безопасный текстовый preview редактора, dialog/Escape/return focus, пагинация, двойной диапазон, live reduced motion и отсутствие текущего пользовательского ввода в экспорте — 11 проверок.
- Независимый `glass_qa`: 16 Theme Studio + 11 Clipboard/dialog/download + 6 настоящего file:// download + 8 motion/drag = 41 проверка. После исправления пустой details-оболочки повторены 17 затронутых проверок. Скриншоты desktop/mobile light/dark и 2D/3D просмотрены, открытых замечаний по этому объёму нет.
- Сборка и статические проверки включают 19 хешей исходников экспортного пакета, восемь сочетаний темы/материала/края и проверки невалидных настроек.

## Исправления при проверке

Изолированные обработчики больше не требуют DOM соседних карточек. Вкладка копирования защищена от позднего Promise; редактор темы честно сообщает копирование предыдущей версии при изменении настроек. Экспорт сохраняет только исходный пример, а не пользовательский ввод. Пустые родительские details стали нейтральными оболочками, собственные раскрытия сохранены.

Параллельная эмуляция media в общей CDP-сессии давала противоречивый matchMedia. Финальные media-проверки выполняются последовательно. Отдельно обнаружен конфликт специфичности CSS пользовательской темы с prefers-reduced-transparency; системный fallback получил равный приоритет и располагается после палитр.

## Ограничения

Проверен локальный Chromium через выделенный CDP bridge. Физические устройства, Safari/Firefox, полная WCAG-сертификация и FPS не заявляются. Расчёт контраста относится к указанным подложкам; произвольные фотографии в проектах-получателях требуют повторной проверки. CSS/JS пакет содержит общие правила и обработчики семейства, хотя DOM включает один пример. Экспорт не добавляет backend к локальным demo.

Точные результаты финального regression и публичной публикации: `evidence/code-theme-release.json` и `docs/release-code-theme.md`. Тяжёлые скриншоты/скачанные HTML остаются в игнорируемом `qa/`.
