# V5 — таблицы и графики

Дата: 2026-10-22. Владелец сборки: `data_finish` (collaboration fallback), независимая приёмка выполняется другим агентом.

## Состав

Группа 15: реестр с сортировкой, фильтром и массовым действием; раскрываемые записи; редактирование целого числа с валидацией. Группа 16: 12 SVG-диаграмм в девяти семействах — сравнение, время, распределение, связи, доли, иерархия, потоки, условная география и мониторинг.

Графики используют учебные массивы A/B и содержат точную таблицу значений. Столбцы начинаются от нуля; line разрывается в null; гистограмма сохраняет 24 наблюдения при смене интервала; Sankey сохраняет вход/выход; цвет легенды дополняется подписями и таблицей. География — авторская условная схема, не реальные территории. Контрольные границы — фиксированный учебный пример, не статистическая оценка.

Внешнюю стеклянную оболочку контролирует координатор. Плоскость данных сохраняет стабильную заливку и плоское кодирование значений во всех четырёх материалах. На узком экране SVG имеет отдельную прокручиваемую область с клавиатурным фокусом; вся страница не расширяется. Контур фокуса не считается декоративным outline.

## Действия для приёмки

| Пример / селектор | Действие | Наблюдаемый результат |
|---|---|---|
| `[data-uid-inventory]` | Сортировать количество, фильтр Frost/Prism, выбрать, отметить готовыми | Числовая сортировка; выбор сохраняется за фильтром; статус обеих выбранных строк меняется |
| `[data-uid-expandable]` | Enter на summary, общая кнопка раскрыть/свернуть | Одна либо все три записи показывают дополнительные поля |
| `[data-uid-inline-row=Frost]` | Ввести 100, затем 7, Enter; новое значение и Escape | 100 отклоняется; 7 даёт 35 баллов; Escape возвращает последнее сохранённое число |
| `[data-uid-chart]` | Набор B, скрыть значения, раскрыть таблицу, сброс | SVG, доступное описание и таблица обновляются вместе; таблица остаётся открытой |
| `bar` | Порядок по убыванию | Набор B: 35,30,25,10 |
| `grouped`, `line`, `scatter`, `stacked` | Выключить обе серии, включить одну | Явное пустое состояние; доступная сводка соответствует выбранным сериям |
| `histogram` | Интервал 2 | 8 интервалов, сумма частот 24 |
| `treemap` | Оптические | Два листа, сумма 40 в наборе B |
| `sankey` | Набор B | 9 потоков с суммой 120; равный вход/выход |
| `control` | Набор B | Два ромба вне границ 35/65 |

Движение: семантические значения меняются сразу, WAAPI через общий `api.animate` подсвечивает итог 240 мс. Нет анимации величин, бесконечных циклов и локальных таймеров. Cleanup снимает собственные listeners и отменяет feedback. Системный reduced motion проверяется до загрузки.

## Проверка

Реальная браузерная проверка: `node tests/ui-v5/data.cjs`. Скрипт подключается к существующему CDP 9223, создаёт собственный контекст и сохраняет результат в игнорируемый `qa/ui-v5/data.json`.

2026-10-22: последовательный прогон завершён **17/17 PASS**, проверены действия всех 15 образцов, отсутствие page errors, numerical invariants, reduced motion до загрузки и узкий экран 390 px. `matchMedia` подтвердил reduce=true, `UIAtlas` — ноль активных feedback-анимаций. Desktop light/dark и mobile screenshots просмотрены вручную: подписи и таблицы читаемы, серии различаются штриховкой. В длинных element screenshots попадает fixed header; для публикационного кадра нужен viewport capture с отступом. Это не доказательство теста на физическом телефоне или Safari.

Независимый визуальный reviewer `compositions_finish` нашёл наложение подписи Center 50 на последнюю точку control chart. Подписи Center/UCL/LCL вынесены в отдельную полосу легенды с типом линии и единицами. У светлого золотого сегмента и географических подписей усилен контраст; исходный HTML реестра отсортирован до JS, чтобы `aria-sort` соответствовал строкам.

Среда проверки: параллельные CDP-тесты с media emulation давали противоречивый `matchMedia` в соседних контекстах. Поэтому результат reduced motion принят только после последовательного прогона с `page.emulateMedia` до navigation и read-back в конце. Первые неуспешные прогоны не считаются pass. Чек newContext({reducedMotion:'reduce'}) без явной эмуляции здесь недостаточен.
