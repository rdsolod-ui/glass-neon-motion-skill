## Проверка исправления по исходникам

Псевдослой ограничен тремя затронутыми компонентами, использует существующие theme tokens, наследует скругление и не перехватывает ввод. Дочерний контент имеет собственный stacking layer. В solid, reduced transparency, unsupported backdrop и forced colors декоративный псевдослой скрывается, а родитель получает читаемый плотный фон. JS и обработчики форм/анимаций не изменены этим исправлением.

Финальный source read-back: после этих кадров владелец добавил `.luma-site #custom-material { backdrop-filter:none; -webkit-backdrop-filter:none }`, чтобы прежний shared ID-селектор не возвращал blur на host поверх нового псевдослоя. Наличие и достаточная специфичность правила проверены; это уточнение реализации, проверка runtime после него остаётся за общим QA.

## Границы доказательства

Результат автора `qa/v4-site/report.json` — 28/28 runtime checks — прочитан, но не присвоен рецензентом и не заменяет общий повтор после patch. Координатор и отдельный QA проверяют взаимодействия и окончательную матрицу. Физический телефон, Safari и все браузеры этим отчётом не подтверждаются.
