# V5 — композиционные группы LUMA

## Brief

25 работающих образцов в 10 группах: 01, 02, 04, 09, 10, 11, 13, 14, 22, 24. Сохраняются LUMA, Manrope, светлая/тёмная тема и палитра cyan/lime/lavender/magenta. Подложка читается через 2D-плёнку; локальные грани включаются отдельно. Панели с текстом не получают второй вложенный backdrop-filter. Клавиатурная рамка фокуса сохраняется.

Нативные HTML/CSS/ES modules; конечная анимация обратной связи через общий WAAPI API. Формы, корзина, календарь и редактор работают локально и не отправляют данные. SVG-иконки — одно официальное семейство Phosphor с сохранённой MIT-лицензией; остальные иллюстрации оригинальные CSS-композиции. Новые зависимости не нужны.

Приёмочные границы: это небольшие воспроизводимые компоненты, а не production CMS, auth, payment или сервис рассылки. Загрузка изображений — локальный preview с проверкой формата/размера и освобождением object URL. Перемещение Kanban доступно кнопками и Alt+стрелками. Native dialog отвечает за модальность, Escape и возврат фокуса.

## Motion contract

Владелец feedback transform/opacity — `api.animate`, 180–240 ms после действия. Новое действие отменяет предыдущую анимацию элемента; reduced motion переключается общим API до загрузки и во время работы. Нет autoplay, бесконечных циклов и scroll hijack. Cleanup снимает собственные listeners, отменяет свои анимации, закрывает собственные окна и освобождает object URLs.

## Статус

2026-10-22: 25 образцов реализованы. Собственная проверка `node tests/ui-v5/compositions.cjs` — 45/45; receipt `qa/ui-v5/compositions.json`. Chromium через выделенный CDP 9223, собственный временный контекст. Проверены оба theme, ширины 1440/390/320, live reduced, все действия ниже, отсутствие runtime errors. Дополнительная симуляция pagehide/pageshow с persisted=true проверяет сохранность cart/gallery/calendar, единственный обработчик и восстановление theme observer; это проверка lifecycle-контракта, не доказательство нативного BFCache на всех браузерах. Реальные мобильные снимки `compositions-light-390.png` и `compositions-dark-390.png` просмотрены: календарь, текст и кнопки не обрезаются. Физический телефон и Safari не проверялись.

Это проверка автора. Независимый reviewer `controls_finish` отдельно проверил 25 образцов и обнаружил устаревшее aria-pressed темы при переключении общей кнопкой. Исправление: MutationObserver по `data-theme`, начальная синхронизация, disconnect при cleanup. Reviewer подтвердил оба направления синхронизации повторной проверкой; итог записан в его отчёте.

## Действия для приёмки

| Группа | Селекторы | Действие / ожидаемый результат |
|---|---|---|
| 01 | `[data-uip-action=theme]`, `#uip-accent`, `#uip-density` | Theme и общая кнопка синхронны; акцент меняет локальный preview; плотность меняет отступы |
| 02 | `[data-uip-action=icon-weight]`, `#uip-favorite` | Шесть SVG начертаний; pressed/name и избранное переключаются |
| 04 | `cta-palette`, `banner-close`, `save-collection` в `data-uip-action` | Палитра подтверждается; баннер закрывается/возвращается с фокусом; подборка меняет состояние |
| 09 | `.uip-mini-header a`, `#uip-burger` | Настоящие якоря; меню открывается, Escape закрывает и возвращает фокус |
| 10 | `.uip-breadcrumb`, `page`, `rail` | Якорь раздела; новая тройка карточек; смена панели навигации |
| 11 | `.uip-mini-footer`, `#uip-newsletter` | Footer links открывают раздел/условия; email и consent валидируются без отправки |
| 13 | `content-favorite`, `.uip-faq`, `#uip-content-filter` | Коллекция, native details, видимые карточки по типу |
| 14 | `gallery-next`, `#uip-upload`, `upload-clear` | Ручная композиция; локальный blob preview; очистка URL |
| 22 | `#uip-product`, `#uip-cart-lines` | Product добавляется; количество и удаление пересчитывают сумму |
| 24 | `#uip-task`, `#uip-calendar`, `#uip-editor` | Alt+стрелки и кнопки перемещают Kanban; дата/месяц/arrow keys; безопасный текстовый preview |

Иконки: локальные SVG и лицензия сохранены с pinned upstream URL и SHA-256 в `site/assets/icons/phosphor/manifest.json`. Все 20/20 файлов совпали с manifest при read-back. Применены CSS dimensions и декоративные aria-hidden; имена действий находятся на кнопках. Ни одного внешнего запроса иконок при runtime.
