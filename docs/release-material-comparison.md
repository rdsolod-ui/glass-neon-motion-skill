# Сравнение материалов — 2026-10-26

## Результат

В Glass Atlas добавлен раздел `#material-compare`. Один из 391 образцов с общей оболочкой показан одновременно в Clear/2D, Clear/3D, Frost/2D и Frost/3D. Десять самостоятельных материальных этюдов исключены из выбора. Сохраняются подписи о фиксированных внутренних техниках Motion.

Тема сравнения независима от основной страницы; можно явно взять настройки атласа. Общий снимок применяется ко всем четырём окнам. Доступны адаптивная ширина, 390/768 px, reduced motion и ручной режим без прозрачности. Большое окно прокручивается внутри ячейки.

Кнопки и безопасные поля связаны по выбору пользователя; связь можно отключить. Пароли, файлы и внешние переходы не зеркалируются. Наведение и клавиатурный фокус остаются настоящими состояниями отдельного окна. Предусмотрены сценарии загрузки, ошибки, формы, progress, dialog и scroll для соответствующих образцов.

Каждая плитка скачивает тот же автономный HTML, который служит её исходным документом: тема, материал и ручной solid сохраняются. Введённые значения и выполненные действия в файл не записываются; он открывается в исходном состоянии. API `GlassExport.build` расширен явным проверенным снимком темы и параметром `solid`, прежние вызовы продолжают работать.

## Исправленные дефекты

- Разрешение `allow-forms` добавлено в доверенные iframe сравнения, предпросмотра и общего экспорта. Без него браузер блокировал событие submit до локальной валидации. Общий runtime предотвращает фактическую отправку, не мешая локальным обработчикам формы; `method="dialog"` и `formmethod="dialog"` сохраняют нативное закрытие диалога.
- После связанного Escape каждый runtime восстанавливал фокус в собственный trigger, и последний iframe забирал фокус. Теперь завершение связанных close возвращает его в исходное окно после локальных обработчиков.
- При поиске компонент выбирается явно; первый результат не выглядит выбранным при сохранённом предыдущем сравнении. Сценарии действительно disabled до загрузки четырёх окон. Отменённые загрузки и их таймеры очищаются.
- Переход из карточки в сравнение мгновенный: предыдущая плавная прокрутка не конкурирует с фокусом или новым выбором.

## Проверка и границы

Локальные проверки координатора: `npm run check` и `npm run build` проходят; новый compare suite — 65/65; регрессия материала — 197/197; автономный smoke — 401/401, без ошибок JS, внешних запросов и overflow. Compare suite включает byte parity скачанных файлов, открытие offline, 320/390/1440 px, системное reduced motion и связанное закрытие dialog с возвратом фокуса.

Независимая приёмка: 46/46 функциональных проверок, 18/18 Escape/Cancel/Save и возврата фокуса, 192/192 проверок оболочек (24 представителя UI-семейств × 4 материала × 2 темы), 16/16 tile export/offline/solid/no-JS, 8/8 accessibility и 4/4 mixed collection forms. Визуально просмотрены все 12 контактных листов; P1 и P2 закрыты повторной проверкой владельцем QA. Полный локальный отчёт: `qa/material-compare-peer/README.md`.

Проверки выполнены на Chrome с desktop/mobile эмуляцией; результаты публикации и численные итоги фиксируются в `evidence/material-comparison-release.json` после выпуска. Визуальная проверка представителей семейств не является полной проверкой всех состояний каждого из 401 примера. Safari, Firefox, физические устройства, FPS и полная WCAG-сертификация не заявляются.

Skill в репозитории дополнен `references/material-comparison.md`; глобально установленная копия навыка не заменялась. Тяжёлые скриншоты и offline-файлы остаются в локальном `qa/material-compare*`.
