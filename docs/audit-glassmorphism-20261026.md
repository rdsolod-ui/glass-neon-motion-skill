# Аудит соответствия glassmorphism — 26 октября 2026

> Исторический срез до исправлений, commit655c3c7. Изменения по этому аудиту: [release-material-contract.md](release-material-contract.md). Скриншоты находятся в локальном каталоге QA и не публикуются с исходниками.

**Вывод: ощущение подтверждено.** В проекте есть рабочие стеклянные материалы, но они не образуют единую систему. Основная проблема — разные семейства и локальные примеры по-разному применяют выбранный материал. В ряде мест стекло есть только у карточки-контейнера. Обнаружен и функциональный дефект: светлый Smoke почти скрывает текст.

Это аудит текущего состояния, без изменения сайта и без новой публикации.

## Основание и объём

- Публичные `index.html` и `moodboard.html`; проверены 26.10.2026. HEAD `655c3c7`, последняя реализация `3107381`.
- Шесть ключевых публичных файлов совпадают с Git после нормализации LF/CRLF. Первичное побайтовое сравнение с Windows-копией давало различие переводов строк; это не расхождение релиза.
- Chrome 156 headless, Windows; реальные скриншоты 1440×1000 и 390×844, light/dark. Сняты четыре сочетания Clear/Frost × Film/Depth через живую тему. Для анализа переключения стилей опрошены все 401 зарегистрированный образец; визуальный просмотр выборочный, а не всех 401.
- Критерий: согласованный проектом clear + depth; фон виден сквозь материал, Frost рассеивает его, Clear сохраняет резкость; 2D без фаски, 3D с локальными затухающими бликами; без постоянного декоративного outline. Текст и данные сохраняют читабельность.
- Источники критериев: `AGENTS.md`, `skill/glass-neon-motion/references/surface-finishes.md`, `acceptance.md`. Физически точную рефракцию аудит не требует.

## Что уже соответствует направлению

- Clear/Frost и Film/Depth действительно различаются в сравнительной лаборатории; прозрачность и глубина в hero и типографических карточках видны.
- В проверенных основных оболочках нет обязательной сплошной обводки. Старые CSS-объявления border не были автоматически засчитаны как дефект: у текущего `.liquid .optical-pane` и его `::after` computed border равен 0.
- Текст, поля и таблицы вправе иметь плотные фоны. Их нельзя массово обесцветить ради эффекта.
- Цветная типографика и конечная анимация сами по себе не противоречат glassmorphism.
- Фиксированные учебные композиции имеют право на свой материал: `.mini-ui` и `.ma-pane` держат blur12px при разных общих режимах. Это не самостоятельный дефект, пока независимость явно обозначена; проблема возникает при обещании общей темы для всей подборки.

Смежное замечание: заголовок главной фактически имеет weight550, тогда как последняя типографическая работа заявляла жирные акценты. Это отдельный дрейф каскада (`mainFonts` в detail.json), а не определение glassmorphism.

## Следующий этап исправлений

1. Исправить G1 и синхронизацию локальных материалов с общей темой; тестировать текст вместе с фоном.
2. Установить для каждого образца явный режим: следует общей теме / фиксированный этюд / нативный контроль. Убрать двусмысленное обещание, что один переключатель уже управляет всем.
3. Объединить материал оболочек и внутренних поверхностей через общие tokens, сохранив читаемые text/data wells. Проверить реальную модалку, tooltip, navigation, progress, HTML и экспорт.
4. Затем визуально откалибровать блики, кромку и площадь плотных подложек. Принимать одни и те же компоненты в light/dark × clear/frost × film/depth, на общем контрастном фоне, включая standalone и общий экспорт.

Больше новых компонентов до этого этапа добавлять нецелесообразно: иначе несогласованность будет расти.
