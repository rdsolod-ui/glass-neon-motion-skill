# Типографика WowPovod → Glass Atlas

Источник: [страница площадок](https://wowpovod.ru/ploshchadki/). Исследовано 27 октября 2026 в Chrome: 1440, 768 и 390 px, реальные computed styles и платформенные шрифты. Это датированный снимок, а не универсальная спецификация сайта.

## Наблюдения

| Роль | Desktop 1440 | Mobile 390 | Принцип |
| --- | --- | --- | --- |
| Главный заголовок | 62 px / 760 / 1.04 / −.035em | 34 px / те же вес и интервал | Плотная крупная форма, короткая фраза |
| Заголовок каталога | 72 px / 740 / .98 / −.036em | 32 px / 740 / 1.04 / −.03em | Большой масштаб раздела, цвет внутри строки |
| Название карточки | 24 px / 740 / 1.08 / −.026em | 20 px / 740 / 1.08 / −.022em | Заголовок компактнее описания |
| Вводный текст hero | 21 px / 450 / 1.5 | 17 px / 450 / 1.5 | Более спокойный вес и просторный интервал |
| Описание карточки | 14 px / 400 / 1.5 | 13.5 px / 400 / 1.5 | Нейтральный текстовый гротеск |
| Длинный текст | 16 px / 400 / 1.78 | 15 px / 400 / 1.7 | Ограниченная строка, паузы между абзацами |
| CTA | Onest 15.5 px / 700 | Onest 15.5 px / 700 | Вес, а не прописные буквы, задаёт приоритет |
| Служебные метки | Моноширинный шрифт, около 11–12 px | Та же компактная роль | Малый кегль, разрядка, табличные цифры |

В CSS объявлены Bricolage Grotesque для display, Onest для акцентов, Inter для текста и JetBrains Mono для служебных элементов. Проверка `CSS.getPlatformFontsForNode` показала смешанную отрисовку заголовков: часть кириллицы фактически Arial, цветные слова Onest, отдельные знаки Bricolage. Поэтому одно только `font-family` из computed style не доказывает реальный шрифт каждого глифа.

## Адаптация для LUMA

- Новый scoped editorial-профиль: Onest для заголовков, акцентов и действий, Inter для текста. Для чисел и меток достаточно существующего системного mono fallback. Остальной атлас сохраняет Manrope.
- Двенадцать новых оригинальных композиций. Переносятся роли, ритм, контраст весов, короткие цветовые фразы и размерная иерархия. Фотографии, коммерческие данные и тексты WowPovod не копируются.
- Цвета адаптированы к светлому и тёмному стеклу. Светлые декоративные цвета источника не переносятся автоматически на мелкий текст. В forced colors цветная фраза становится обычным читаемым текстом.
- Кегль рассчитывается по ширине компонента, чтобы длинный заголовок работал в атласе, отдельном HTML и подборке. Минимальные подписи увеличены до 12–13 px, основной текст до 16 px.
- Display использует вес 760, section/card 740 при стандартной теме 800. Настройка веса в Theme Studio меняет их согласованно через `--gt-heading-weight`; относительная иерархия сохраняется. Никакого курсива и засечек.
- Движение остаётся существующим конечным WAAPI-появлением LUMA. Анимация источника не выводится из скриншота и не копируется.

## Шрифты и источник измерений

Onest и Inter загружены как локальные WOFF2: Latin и Cyrillic, объявленный диапазон 400–800. Четыре файла занимают 116 624 байта. Лицензии OFL лежат рядом с файлами в `site/assets/fonts/editorial/`; URL, SHA-256 и ревизии upstream — в [typography-font-sources.json](typography-font-sources.json). Лицензия шрифта не является лицензией на фотографии или тексты сайта.

[Компактная запись измерений](../evidence/typography-reference-wowpovod.json) содержит значения, платформенные шрифты и хеши CSS. Подробные computed styles и скриншоты находятся локально в `qa/wowpovod-type/`. QA не загружается в GitHub целиком. Проверка на одном Chrome не доказывает одинаковую растеризацию на всех ОС и браузерах.
