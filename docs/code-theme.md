# Theme Studio и экспорт образцов

В Glass Atlas доступен редактор двух палитр, Clear/Frost, Film/Depth, радиуса панелей, плотности внутренних отступов и длительности/easing отклика. Кнопка «Код и экспорт» открывает исходный образец с текущим снимком темы.

Три вкладки соответствуют `sample.html`, `sample.css` и `sample.js`. Сохраните их рядом или скачайте единый автономный HTML. Шрифты и иконки встроены; внешние ссылки на источники остаются ссылками. В экспорт не входят введённые данные, файлы пользователя и соседние карточки. Ограничения исходного образца сохраняются: 48 визуальных композиций не превращаются в полноценные продуктовые компоненты, а HTML-рецепты и контролы без медиа явно отмечены.

Покрытие: 76 UI + 44 варианта + 115 HTML/namespace + 22 типа input + 12 состояний + 39 motion + 48 композиций + 4 материала + 6 optical studies = 366. 23 сторонних референса и 10 ссылок-источников не экспортируются.

Генерация: `node scripts/render-atlas.mjs`. Она обновляет страницу и один общий `site/export-assets.js`. `npm run check` сравнивает SHA-256 исходников с ресурсным пакетом. Не редактируйте пакет вручную. Сборка: `npm run build`.

Собственные обработчики умеют работать без соседних демонстраций; общий UI bootstrap в экспорте не запускает поиск по атласу. Статические сравнения материалов сохраняют заданную поверхность. Размеры и тема применяются к поддерживаемым панелям, не подменяют семантику стандартных HTML-элементов.

Браузерные тесты: `tests/code-theme-peer/expected-coverage.mjs`, `export-smoke.cjs` (все образцы с блокировкой запросов), `qa-theme.cjs` и независимые QA-сценарии. Массовый smoke не является проверкой всех возможных действий: отчёт релиза отдельно перечисляет функциональные сценарии и ограничения.
