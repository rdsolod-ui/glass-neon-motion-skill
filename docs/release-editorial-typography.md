# Editorial Typography — 27 октября 2026

## Что изменилось

В Glass Atlas добавлены 12 оригинальных композиций по типографическому ритму страницы [WowPovod / Площадки](https://wowpovod.ru/ploshchadki/). Всего теперь 47 типографических образцов и 413 образцов в каталоге; 403 с общей оболочкой доступны в сравнении материала.

Новый набор: главный экран, заголовок раздела, карточка, характеристики, метки и счётчики, крупное число, длинное чтение, цитата, действия, вопрос-ответ, цена и кириллица/латиница. Stable ID начинаются с `type-editorial-`; прежние ID сохранены. Все новые образцы поддерживают подборки, четыре материала, автономный HTML и ZIP.

Заголовки и акценты используют Onest, основной текст — Inter. Четыре локальных WOFF2 (Latin/Cyrillic) занимают 116 624 байта; OFL включены в репозиторий и экспорт. Manrope остаётся в остальных образцах. Значение веса в Theme Studio передаётся через `--gt-heading-weight`, сохраняя относительную иерархию нового набора.

[Точные измерения и решения адаптации](typography-reference-wowpovod.md) разделяют объявленный CSS и фактические шрифты: в референсе часть кириллицы подменялась Arial. Это смешение не перенесено в новый профиль. Не копировались фотографии, коммерческие данные и тексты WowPovod.

В export capture также исправлены fragment-ссылки: если целевого ID нет внутри выбранного примера, ссылка ведёт в соответствующий раздел исходного атласа. Ссылки на локальные элементы остаются локальными.

Skill дополнен `references/editorial-typography.md`; README и актуальные счётчики обновлены. Глобально установленная копия навыка не заменялась.

## Проверка

Локально: check/build pass; 88/88 targeted typography checks, включая 12 образцов в двух темах на 1440/390/320 px, фактическую загрузку Onest, веса, FAQ, reduced motion и mixed export; 413/413 автономных примеров без ошибок JS, внешних запросов и overflow; 65/65 регрессии сравнения материалов.

Независимая приёмка: 41/41 основных и 8/8 дополнительных проверок, 48 скриншотов и четыре контактных листа просмотрены. Дополнительно осветлены вторичные подписи нового профиля в dark: после изменения 28/28 выборочных измерений контраста по областям символов прошли с минимумом 4,81:1. Первичная оценка по полному прямоугольнику текста была консервативной; точный контраст символов до исправления не устанавливался. Это выборочная проверка композитных фонов, не полная WCAG-сертификация. Локальные материалы — `qa/editorial-typography-peer/README.md`. Публичный read-back фиксируется отдельно после deploy.

## Ограничения

Chrome desktop/mobile emulation; не заявляются одинаковая растеризация во всех ОС, физические устройства, все движки, полный WCAG-аудит или FPS. Локально поставляются Latin и Cyrillic subsets; другие письменности используют стек fallback и требуют отдельной проверки. Снимок референса относится к 27 октября 2026.
